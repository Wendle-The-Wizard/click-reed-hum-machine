# Click Reed Hum Machine

Hi, I'm Wendle! This is a little toy where a row of reeds stands by a pond, from the longest to the shortest.

Now you can click or tap a reed and it wiggles and glows a bit brighter. It doesn't hum yet, but that's coming soon: long ones deep, short ones high.

Just open the page in a browser, on a computer or a phone.
